Install the console

Add Glaron Admin to your device so it opens like a normal app — and so new-order alerts can reach you when it is closed.

Installed. You are running the app version.

Installed — open “Glaron Admin” from your home screen to continue.

On iPhone / iPad (Safari)
  1. Tap the Share button at the bottom of Safari.
  2. Scroll down and choose Add to Home Screen.
  3. Tap Add, then open Glaron Admin from your home screen.

On iPhone and iPad the app can only be added from Safari. Open this page in Safari, then follow the steps above.

On Android / desktop
  1. Open the browser menu (⋮).
  2. Tap Install app or Add to Home screen.
  3. Open Glaron Admin from your home screen.
